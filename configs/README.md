# configs/

Rules chosen **in advance** of running an experiment: which operator,
which k, which theta/comparator, which model backbone, which questions
were pre-registered into a subset before any inference was spent on them.

This is the opposite of `artifacts/`, which holds what those rules
*produced* once applied to a completed run (eligibility lists, trigger
sets, computed Delta values) - conflating the two risks implying a routed
set was known before scoring, which it wasn't.

- `thresholds/` - the CARVE decision rule and the E3 ablation grid, as
  YAML, not scattered as hardcoded constants across run scripts.
- `models/` - backbone/agent settings frozen before production inference
  (Section 6's "Primary agent and backbone").
- `experiments/` - pre-registered subset selections (which N questions a
  compute-matched baseline runs on, chosen by seed + stratified sampling
  *before* execution) and smoke-test configs. These are technically
  generated by `baselines/_common.py`'s `select_subset`, but conceptually
  they're inputs fixed before the expensive run, not outputs of one - see
  `select_subset`'s own docstring: "The chosen list is written to disk
  BEFORE any question is executed."
